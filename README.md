# databricks-azure
📊 Monitoramento de Custos no Azure Data Factory (Monitoramento Básico)
Este guia mostra como configurar um monitoramento básico das execuções de pipelines no Azure Data Factory (ADF), com foco na identificação dos custos relacionados ao tempo de execução e quantidade de atividades processadas.

🧭 1. Acesse o Azure Portal
Acesse o portal oficial da Microsoft:
🔗 https://portal.azure.com

Faça login com sua conta.

Certifique-se de estar no directório e assinatura corretos.

 ![Home](https://github.com/robinson-17/databricks-azure/blob/main/00-01.jpg)

---

🏭 2. Acesse sua instância do Azure Data Factory
No menu lateral esquerdo, Clique sobre o nome da sua instância do ADF.

📸![ADF](https://github.com/robinson-17/databricks-azure/blob/main/00-55.jpg)

---


📁 3. Acesse a aba de Monitoramento
No painel lateral do ADF, clique em "Monitoramento" (ou “Monitor”).

![Monitor](https://github.com/robinson-17/databricks-azure/blob/main/00-14.jpg)

---


📉 4. Visualize os detalhes das Execuções (Monitoramento Básico)
Clique em uma das execuções da tabela para ver os detalhes da execução.

💡 Importante: O custo do ADF é diretamente influenciado pela duração da execução e pelo tipo/quantidade de atividades realizadas. Monitorar esses dados ajuda a evitar desperdícios.

![Execuções](https://github.com/robinson-17/databricks-azure/blob/main/00-48.jpg)

---

🎯Conclusão:

Com esse processo, você configura um monitoramento básico e prático dos custos no Azure Data Factory, sem depender de integrações externas. Este tipo de visualização é essencial para:

✅ Controlar o tempo de execução dos pipelines

✅ Identificar gargalos e execuções desnecessárias

✅ Ter noção dos custos operacionais antes de escalar o uso
